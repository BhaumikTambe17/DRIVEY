# DriveFix - VS Code Only

This version is a simple local website. It does NOT need Supabase, Vercel, Node.js, a server, an API key or a paid service.

## Run it
1. Open this folder in Visual Studio Code.
2. Open `index.html`.
3. Either double-click `index.html` in Windows Explorer, or install the free **Live Server** extension in VS Code and click **Go Live**.
4. The website opens in your browser.

## Customer demo
- Sign Up with any name, phone, email and password.
- After signup, the vehicle registration page opens automatically.
- Register the vehicle.
- Select a problem.
- Add a description.
- Submit the repair request.

## Owner demo
Click **Owner Login**.
- Email: `owner@drivefix.demo`
- Password: `admin123`

The owner dashboard shows the customer requests saved in this browser.

## Important limitation
This is a local/demo version. `localStorage` is used, so customer data is stored only in the browser/device where the website is opened. A customer using a different phone cannot send a request to your computer without adding a real online database later.
